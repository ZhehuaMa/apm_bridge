## 3. 坐标系与符号约定（核心，实测定案）

### 3.1 坐标系与欧拉角（2026-11-08 依原文附录1/2 重读修订定案）

- **载机坐标系**（原文附录1 图几何重建＋实测自洽；附录1 仅透视图无文字轴向标注）：**X 前、Y 右、Z 下（FRD 式右手系）**。`uav.angle` 的 [滚转,俯仰,偏航] 即按该系 X/Y/Z 语义排序（符号 [未验证]，本项目恒 `valid=0`，见 §5.2）。
- **相机坐标系**（原文附录2）：**X 左、Y 前（光轴）、Z 下 —— LFD 式右手系，与载机系不同**！两系仅差绕 Z（下轴）的 90° 偏航：X_cam = −Y_body（左）、Y_cam = X_body（前）、Z_cam = Z_body（下）。原文附录2 角度转换中的 **`ψ+=90` 正是这个 90° 帧差在偏航数据基准上的体现**（偏移符号方向 [未验证]；无 uav 融合时不影响任何使用）。云台减震平台平行载机 XOY 面；立装/吊装由固件经 `inv_flag` 内部补偿，**上位机公式不随安装方式变化**（立装实测）。
- **φ/θ/ψ 是相机 LFD 系欧拉角**，遵循惯用的"字母↔轴号"对应（φ↔X、θ↔Y、ψ↔Z）。由于 LFD 系的 X=左是俯仰轴、Y=前是滚转轴、Z=下是偏航轴，因此 **φ=俯仰、θ=滚转、ψ=偏航**——并非"命名与惯用互换"，而是轴的物理含义随坐标系改变。各轴正方向均为绕该轴右手正转：**φ>0 = 低头、θ>0 = 右滚、ψ>0 = 右转**。
- **旋转顺序 Z → Y → X = 偏航 → 滚转 → 俯仰（Yaw→Roll→Pitch，ZXY）**，**不是**航空惯用的 Yaw→Pitch→Roll（ZYX，Betaflight 姿态即 ZYX）。单轴运动下两者等价；多轴大角度合成时不同。由 cam_angle 重建相机姿态（载机 FRD 基）必须用 ZXY：
  `R_cam = Rz(cam_angle[2]) ⊗ Rx(cam_angle[0]) ⊗ Ry(cam_angle[1])`（抬头正域）
  驱动的 ZXY 运动学链 `gimbalCameraToWorld`（yaw⊗roll⊗pitch，`gimbal_kinematics.h`）与此同构——原先仅以"物理关节序"为由采用 ZXY，现获得协议层证实。
- **cam_angle 是 FRD 载机系表示**（φ/θ/ψ 才是 LFD 相机系欧拉角）。附录2 原文转换式：
  `ψ+=90；cam_angle[0]=+θ；cam_angle[1]=−φ；cam_angle[2]=+ψ`
  （括注符号语义为实测结果：右滚/抬头/右转正，与 LFD 轴向推导一致。）
  单轴映射关系：相机 Y 轴（前）↔ 载机 X 轴（前）、相机 X 轴（左）↔ −载机 Y 轴（右）、相机 Z 轴 ↔ 载机 Z 轴（下）。**§3.2 符号总表的全部实测符号均可由"LFD 轴向 + 右手正转 + 本转换式"直接推出**，模型闭环。
- **轴序的统一解释**：`cam_rate`/`mtr_angle` 按**相机 LFD 系轴序** [X,Y,Z] = [俯仰,滚转,偏航] 排列，各通道正方向 = 绕对应 LFD 轴右手正转（俯仰通道低头正、滚转通道右滚正、偏航通道右转正）；`cam_angle` 与发送包 gbc 槽序按**载机 FRD 系轴序** [X,Y,Z] = [滚转,俯仰,偏航] 排列。§2.2/§5.3 的"轴序陷阱"即源于两组域分属两个坐标系。
- `cam_rate` 语义（注释27"云台 IMU 输出的角速度"）：**体轴角速度**而非欧拉角速率（术语表"欧拉角速度"的措辞仅在单轴/小角度下与体轴速率一致）。按分量重排+变号做坐标系转换，对体轴角速度是**精确**的；欧拉角速率则需经角速度合成，不可直接重排。

### 3.3 域间关系（由 §3.1 模型导出，台架实测验证）

```
cam_angle[1] ≈ −mtr_angle[0] + δ        δ = 水平基准慢漂 1~4°（无 uav 融合时）
cam_rate[0]  = −d(cam_angle[1])/dt      （cam_angle[1]=−φ, cam_rate[0]=+φ̇ ⟹ 反号）
cam_rate[1]  = +d(cam_angle[0])/dt      （cam_angle[0]=+θ, cam_rate[1]=+θ̇ ⟹ 同号）
cam_rate[2]  = +d(cam_angle[2])/dt      （cam_angle[2]=+ψ, cam_rate[2]=+ψ̇ ⟹ 同号）
偏航姿态漂移 ≈ −0.18°/s（无 uav 融合时，地面静止实测）
```

导出关系在单轴/小角度下严格成立；多轴大角时 cam_rate 为体轴速率，与欧拉速率之间差一个运动学耦合项（§3.1 末条）。

## 4. 命令行为（实测）

**FPV 跟随的重要实测结论（2026-10-27）**：无 uav 融合数据（valid=0）时，固件 FPV 模式**不随机身转动**（表现为 LOCK 式世界保持）。因此本项目的 AIM（机身 +Z 上视）实现为 **LOCK+真实角速度 + P(位置增益 `gimbal.aim_follow_gain`，默认 8) + FF(机身俯仰速率前馈)**，不依赖云台 FPV/uav 融合（约定 `send_uav_data` 恒 false）。真机实测（C20S）：跟随滞后 **~0.03s**（角度域方案为 0.15s），270°/s 手甩最差相对角 14.8° 且静止后完全恢复，静止段相对角 σ ≤ 0.07° 无振铃；速率通道 1:1 即时响应是低滞后的根基。

| 命令 | 行为 |
|---|---|
| 2 启动 | 上电自动启动；**STOP 后必须 START 才恢复受控**，实测 0.5s 内回平 [实测] |
| 3 停止 | 电机断电、增稳失效，相机会下垂；仅供通电存储场景 [原文][实测] |
| 4 手动 | 常态命令；`trig` 每包递增即可重复执行；命令 5/6 期间 gbc 速度应清零由固件闭环 [原文+驱动约定] |
| 1 陀螺校准 | 需 `tca_flag=1` 且云台静止，历时数秒 [原文] |
| 5/6 指点/内置跟踪 | `target_angle` 为目标偏离画面中心角（水平右正/垂直**下正**）[原文] |
| trig 规则 | 命令码变化立即执行；同码重复执行需变 trig [原文] |
| go_zero 回中位 | **真机 C20S (fw38) 完全无效**：单轴/三轴、0→1 边沿或持续置 1，均不触发回中动作，也不干扰后续控制命令（LOCK 速率/角度照常受理）。上电/START 的自动回平目标是 cam=0（水平，编码器停在水平偏置 ~+5-6°），**不是编码器零点** [2026-10-30 实测，probe_go_zero.py / probe_fpv_to_lock.py] |

**机械零点（编码器零点）回中原语（2026-10-30 实测定案）**：`FPV + 角度 op=0 + fl_sens=15` 精确驱动 `mtr → 0`（FPV 相对角零点 = 编码器零点），~80° 行程 0.2-1s 到位。驱动的启动回中（`gimbal.home_on_connect`）即用此原语；go_zero 边沿仅为其它机型兼容保留（~100ms 脉冲）。LOCK+角度 op 的目标域是 cam 姿态角（0=水平 ≈ 编码器 +5-6°），与编码器零点不同域，勿混用。

**fl_sens**（FPV 跟随灵敏度，仅 FPV 模式生效）：`0` 时相对角跟踪极慢（实测 ~0.2°/s 爬行，AIM 类应用不可用）；`15` 干脆收敛（实测 80° 目标 0.5s 内到位）。[实测]

**保护**：任意轴 FPV → 全轴 FPV 且倾角保护无效；俯仰/滚转轴禁用跟随模式 [原文]。样机已解除转动限制（实测 cam+108° 无保护触发）。

## 5. 使用注意（实测汇总）

1. **水平基准漂移**：无 uav 融合时姿态基准慢漂（1~4°，yaw −0.18°/s），FPV/编码器域不受影响，但 LOCK 姿态保持与 AIM 绝对精度受其限制（≈±2°）。任务前留自平时间。
2. **uav 融合**：`uav.angle`（滚转/俯仰/偏航）与 `accel`（NEU）的符号约定未实机验证——在按附录 C 方法判别前**务必 `valid=0`**。
3. **轴序陷阱**：发送包 gbc 槽序 [滚转,俯仰,偏航]；接收包 `cam_rate`/`mtr_angle` 是 [俯仰,滚转,偏航]，`cam_angle` 是 [滚转,俯仰,偏航]。根源（§3.1）：gbc/cam_angle 按载机 FRD 轴序，cam_rate/mtr_angle 按相机 LFD 轴序——两个坐标系各自的 [X,Y,Z]。
4. **俯仰双域陷阱**：编码器（低头正）与姿态角/命令 op（抬头正）反号；FPV 相对角命令 = −编码器。
5. **C40D/C200T 增补**：滚转/偏航编码器符号在单轴机不可测（恒 0）。按 §3.1 统一模型（编码器 = 绕相机 LFD 轴右手正转）**预测 `mtr_angle[1]` 右滚正、`mtr_angle[2]` 右转正**（与 cam_rate 同号系；俯仰"低头正"已被 C20S 实测证实为该模型的特例）。驱动侧两处多轴位点已按该预测对齐（2026-11-08 对抗复审发现旧"全轴编码器反号"假设残留）：MISSION 限位门（`updateMissionControl`）与 LOCK 角度轨迹播种（`smoothAngleCommands`）不再对滚转/偏航编码器取反；位姿链 `gimbalCameraToWorld` 与测试假云台本就按同号实现。**若实机复验推翻预测，需同步回改这两处及位姿链**。多轴 ZXY 合成序（物理关节链 yaw⊗roll⊗pitch）同样待多轴机复验。上电后建议先做小角度阶跃复验（附录 C.1/C.5）。

## 附录 C：台架判别方法（换机/换固件后复验用）

1. **角度域**：LOCK+角度 ±10° 阶跃，读 cam/mtr 收敛值 → 得姿态域符号与姿态↔编码器关系。
2. **速率域**：真实角速度 +30°/s ×3s，看 cam 积分方向与 cam_rate 读数 → 得速率命令域与陀螺域。
3. **FPV 域**：FPV+角度 ±20°（fl_sens=15），看 mtr 收敛 → 得相对角命令与编码器关系。
4. **绝对方向**：A/B 两段式 ±30° 摆动肉眼判别抬头/低头方向（唯一需要人眼的外部基准）。
5. **滚转/偏航**：手动右滚 20~30°、左偏航 60~90°（往返），对照 cam_angle/cam_rate 变化方向；多轴机（C40D/C200T）另复验 mtr_angle 符号预测与 ZXY 合成序（§5.5）。
